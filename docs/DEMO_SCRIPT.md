# Sensei, five-minute demo script

Live site: https://54-80-119-54.sslip.io. Two Chrome windows signed in before you start: Maya (maya@apollo.demo) and Priya (priya@apollo.demo), plus Slack open on #all-sensei. Answers take 2 to 10 seconds; let each finish before you speak the next line. Never show the Meet bot. If a step fails, redo it; never narrate an error.

| Time | Do this on screen | Say this |
|---|---|---|
| 0:00 | Landing page, hold on the headline for two seconds, then scroll slowly to the four question cards. | "Every team has one person everyone interrupts. Where is the rollback runbook. Who owns notify-service. Why don't we deploy on Fridays. The answers exist, in Confluence, in Jira, in a Slack thread, in a meeting nobody wrote down. New joiners lose weeks finding that person, and that person loses hours being found. A chatbot doesn't fix this, because the knowledge isn't in a chat." |
| 0:30 | Scroll to "You onboard it like a hire." | "Sensei is a colleague a project owner onboards, not a bot you prompt. You give it what you'd give a new hire: the wiki, the repo, the tickets, the Slack channel, and accounts on the tools. Then it goes to work for the whole team." |
| 0:45 | Maya's window: Sources page, hover the list: GitHub, Confluence SD, Jira KAN, Slack, four files, a URL. Then Tools: the GitHub connection, open the tool list, point at "read" and "write" labels and the "Allow writes" switch. | "This is Apollo Delivery, a real sample project. Maya connected six kinds of sources and a GitHub account. Every tool that account gives Sensei is classified read or write, and writes are off until Maya turns them on. That decision is a switch, not a prompt." |
| 1:10 | Priya's window: her Brief page. Scroll it once, stop on "What nobody wrote down." | "Nobody asked Sensei anything yet. When Maya added Priya, it researched the project and wrote her this brief before her first login: what the system is, how it ships, who owns what, and the honest part at the end, what the sources can't tell her." |
| 1:30 | Maya's window: Dashboard, the readiness card. Open the list, point at the one marked not in the sources. Click through to Answers, show it in the ledger asked by "Sensei (self-check)". | "Before it starts, it interviews itself: the eight questions a new joiner would ask, answered from the sources alone, graded strictly. Seven of eight here. The eighth is already in the ledger. A human answers it once, in a sentence, and Sensei knows it forever." |
| 1:55 | Priya's window: Chat. Type: **Who is on call the week of 15 September, and what is the production deploy window?** Wait. Expand "Thought for Ns", then the sources. | "Now ask it like a colleague. Watch the steps: it searched the project's documents, then wrote. Daniel is primary, Ravi secondary, Priya release captain, and deploys are Tuesday to Thursday, Irish time, never Friday. Plain sentences, the facts in bold, the pages it read underneath." |
| 2:20 | Chat: **What has Daniel Okafor worked on recently?** Wait. Point at the "Reading the activity records" step. | "Ask about a person and it doesn't search prose. It reads his commits, pull requests and tickets. That's a different tool, and you can see it choose it." |
| 2:40 | Chat: **Put the KAN Jira tickets in a spreadsheet with key, title and owner.** Wait for the download chip. Click it, open the file for two seconds. | "Ask for work and it does the work. It reads Jira live, right now, not from an index, then builds the spreadsheet and hands you the file." |
| 3:05 | Judge window or a member without write access: Chat: **Create a GitHub issue titled "Assign an owner to notify-service".** Show the refusal sentence. | "Ask it to change something the owner hasn't allowed, and it's refused inside the agent loop, not by a polite prompt, and it tells you exactly who can lift that." |
| 3:20 | Slack, #all-sensei. Mention the bot: **@sensie bot what's the production deploy window?** Wait for the threaded reply. Then post, without a mention: **does anyone know when the Fabrikam demo is?** Show the reply in the thread. Then: **lunch anyone?** Show nothing happens. (If live replies are not yet configured, show the existing threads where it already replied and say the same lines.) | "It's in Slack the way a colleague is. Mention it, it answers in the thread with its source. Ask the room something the docs can answer, and it steps in, because it can cite the answer. Small talk, it stays out. Every message in the channel is indexed as it lands, so a decision at ten-oh-two is askable at ten-oh-three." |
| 3:50 | Maya's window: Meetings, start a companion meeting. In the speaker box type Ravi: **We deploy Apollo to us-east-1.** Show the correction with its confidence and source. Then Priya: **Sensei, who owns the routing worker?** Show the answer. Then Priya: **Let's grab lunch after this.** Show the grey "not a factual assertion" line. End the meeting. | "In a meeting it listens. A wrong claim that the documentation contradicts gets a correction, with the source, only above point-eight confidence. Addressed by name, it answers. Lunch plans, it says nothing, and tells you why. When the call ends it writes the notes and indexes them." |
| 4:20 | Trust page. Point at a credential's ceiling and floor, the tools by class, the "never" list. | "Everything it can reach is on one page: what each credential could touch, what Sensei actually reads, which tools may write, and what it will never do. Trust is a page you can read, not a promise." |
| 4:35 | Architecture diagram full screen for three seconds, then a quick code flash: agent.py build_colleague, the WriteGate hook, the Slack service. | "Under the hood it's one Strands agent loop, equipped per question: custom tools, MCP tools from the owner's accounts, a hook that enforces the write gate, a three-agent graph for the briefs, typed outputs everywhere, streamed to the UI. Claude Haiku answers, one container on AWS." |
| 4:50 | Landing page, "Try it now" section with the accounts, then the URL. | "It's live, with a real project onboarded and accounts you can log in with. Sensei. Onboard it like a colleague." |

Words: about 690, which is 140 a minute with room for the pauses while answers stream.
